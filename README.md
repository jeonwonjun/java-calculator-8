# java-calculator-precourse

## 기능 요구 사항
### 1. 문자열(string) 입력 받기
- [ ] 숫자와 구분자가 합쳐진 문자열 입력
- [ ] 숫자만 있는 문자열 입력
- [ ] 구분자만 있는 문자열 입력
- [ ] 빈 문자열 입력

### 2. 구분자 구하기
- [ ] 배열에 커스텀 구분자 저장 후 "//", "\n" 제거
- [ ] 쉼표, 콜론 저장

### 3. 잘못 된 값 입력 시 IllegalArgumentException 출력 및 종료
- [ ] 문자열에 쉼표, 콜론, 커스텀 구분자 이외에 문자가 들어갔는가 

### 3. 구분자로 split하기
- [ ] 구분자를 기준으로 문자열 split
- [ ] split한 개수 고려

### 4. 변환 한 양수, 배열에 저장
- [ ] split된 숫자를 배열에 저장

### 6. 저장된 배열 값의 합
- [ ] 배열의 합 출력

## 입력 및 출력 양식
- [ ] 입력: "덧셈할 문자열을 입력해 주세요.\n"
- [ ] 출력: "결과 : {값}"

## 고려할 점
1. 양수로 구분된 문자열? +가 붙은 채로 올 수 있나?
2. 문자열이 int범위를 벗어나면 어떡하지?
3. 소수로 입력되면?
4. 커스텀 구분자가 여러 개라면?
