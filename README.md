# java-calculator-precourse

## 기능 요구 사항
1. 문자열(string) 입력 받기
2. 잘못 된 값 입력 시 IllegalArgumentException 출력
3. 구분자로 split하기(기본 구분자 - 쉼표, 콜론 / 커스텀 구분자 - "//"+"\n")
4. 구분자에 따른 문자 양수로 변환
5. 변환 한 양수 배열에 저장
6. 저장된 배열 값의 합

## 고려할 점
1. 양수로 구분된 문자열? +가 붙은 채로 올 수 있나?
2. 문자열이 int범위를 벗어나면 어떡하지?
3. 소수로 입력되면?
4. 커스텀 구분자가 여러 개라면?
